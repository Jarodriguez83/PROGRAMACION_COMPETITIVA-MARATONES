# **J. TU NOMBRE**
## **TIEMPO LÍMITE:** 1 Segundo 
## **LÍMITE DE MEMORIA:** 256 MB  

Khba está escribiendo el nombre de su novia. El tiene n cubos, cada uno con una letra latina minúscula escrita en él. Están dispuestos en fila, formando una cuerda s. El nombre de su novia también es una cadena t, que consiste en n letras latinas minúsculas.  

Para demostrar su amor, debe comprobar si es posible reorganizar las letras de la cadena s para que se convierta en su nombre t.  

## **ENTRADA:**

La primera línea contiene un número entero g(1 <= g <= 1000) el número de casos de prueba. 

La primera línea de cada caso de prueba contiene un número entero n (1 <= n <= 20). 

La segunda línea de cada caso de prueba contiene dos cadenas distintas s y t, cada uno de los cuales consta de n letras latinas minúsculas. 

## **SALIDA:**

Para cada caso de prueba, salida "YES" si las letras de **s** se pueden organizar para formar **t**, de lo contrario, salida "NO"

## **EJEMPLO DE PRUEBA:**

### **ENTRADA:**
- 5
- 7
- Humitsa Mitsuha
- 4 
- orhi hori
- 6 
- Nezuqo Nezuko
- 6 
- misaka mikasa

### **SALIDA:**
- YES
- YES
- NO
- NO
- YES
