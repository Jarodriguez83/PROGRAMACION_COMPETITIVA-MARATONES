# **UN TAMIZ DE ERATO67HENES**
## **LÍMITE DE TIEMPO:** 1 Segundo
## **LÍMITE DE MEMORIA:** 256 MB

Se te da **n** numeros enteros positivos a1, a2, ....., an.

Por favor, determine si es posible seleccionar cualquier número de elementos en a, para que su producto sea **67**. 

Tenga en cuenta que no puede seleccionar elementos cero, ya que el producto de elementos cero no está definido para este problema.  

## **ENTRADA:**

Cada prueba contiene varios casos de prueba. La primera línea contiene el número de casos de prueba **t** (1 <= t <= 10000). A continuación, se describe el procedimiento de la prueba.  

La primera línea de cada caso de prueba contiene un único número entero **n** (1 <= n <= 5).  

La segunda línea de cada caso de prueba contiene **n** números enteros positivos. a1, a2, ....., an (1 <= ai <= 67)

## **SALIDA:**

Si es posible seleccionar elementos de manera que su producto sea 67, imprime "YES" en una línea. De lo contrario imprime "NO" en una línea.  

## **EJEMPPLO DE CASO DE PRUEBA:**

### **ENTRADA:**

- 2
- 5
- 1 7 6 7 67 
- 5
- 1 3 5 7 8 

### **SALIDA:**

- YES 
- NO
