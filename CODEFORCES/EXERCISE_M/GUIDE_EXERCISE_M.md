# **M. MALABARISMO CON CARTAS**
## **LÍMITE DE TIEMPO:** 1 Segundo
## **LÍMITE DE MEMORIA:** 256 MB 

Se te da n cuerdas s1, s2, ....., sn compuesto por letras latinas minúsculas.  

En una operación puedes eliminar un carácter de una cadena s-i e insértelo en una posición arbitraria en una cadena s-j (j puede ser igual a i). Puede realizar esta operación cualquier número de veces ¿Es posible hacerlo todo n ¿Cadenas iguales??

## **ENTRADA:**

La primera línea contiene t(1 <= t <= 10) el número de casos de prueba.  

La primera línea de cada caso de prueba contiene un único número entero n (1 <= n <= 1000) el número de cadenas.  

n Las líneas siguen, la i-línea contiene s-i(1 <= |s-i| <= 1000)

La suma de las longitudes de todas las cadenas en todos los casos de prueba no excede 1000. 

## **SALIDA:**

Si es posible igualar las cadenas, imprima "YES"

De lo contrario, imprima "NO"

Puede mostrar cada carácter en minúsculas o mayúsculas.
